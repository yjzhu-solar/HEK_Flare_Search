# HEK_Flare_Search
Search flares for Physics of Space Weather Exercise in case of Solar Monitor down...

## Streamlit app

`app.py` is a small web app that lists flares from the LMSAL HEK
("SSW Latest Events", AIA) for a given time window (UTC) and NOAA active region.
The region number can be given either with or without the leading 1
(e.g. `3664` or `13664`); leave it blank to list all flares in the window.
The results table shows the flare start/peak/end times, GOES class,
NOAA active region and a link to the flare movie, and can be downloaded as CSV.

Run locally:

```bash
pip install -r requirements.txt
streamlit run app.py
```

The query logic lives in `example_notebook/hek_query.py`; see
`example_notebook/test_hek_query.ipynb` for an example of using it directly.
